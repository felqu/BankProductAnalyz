# Анализ отзывов о банковских продуктах

Учебный проект по анализу больших данных. В нём собран полный путь работы с
отзывами: сбор с banki.ru, очистка данных, классификация тональности,
статистические проверки и интерактивный дашборд.

## Что есть в проекте

| Каталог | Назначение |
| --- | --- |
| `parser/` | Сбор отзывов Selenium, подготовка данных и ML-скрипты. |
| `final dataset/` | Итоговый размеченный набор данных. |
| `check/` | Проверка статистических гипотез и анализ уверенности классификатора. |
| `visual/shiny_app/` | Интерактивный дашборд на Shiny for Python. |

Основной датасет — `final dataset/dataset_with_sentiment2.csv`. В нём есть
сведения о банке, продукте, городе, дате, тексте отзыва, оценке и результатах
классификации тональности (`sentiment`, `NEGATIVE`, `NEUTRAL`, `POSITIVE`).

## Быстрый старт

Нужен Python 3.10+ и Google Chrome (только для сбора данных).

```bash
git clone <URL-репозитория>
cd BankProductAnalyz
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```

Для обучения модели и запуска классификации установите дополнительные
библиотеки:

```bash
pip install -r requirements-ml.txt
```

## Запуск дашборда

```bash
shiny run --reload visual/shiny_app/app.py
```

В приложении можно фильтровать отзывы по банку, продукту, городу, тональности
и периоду, а также посмотреть распределения оценок, динамику отзывов и связь
оценок с вероятностями тональности.

## Анализ данных

```bash
python check/hypoteses.py
python check/confidence.py
python parser/EDA.py
```

Скрипт гипотез проверяет связь тональности с банком и продуктом. Скрипт
`confidence.py` сохраняет график `check/confidence_distribution.png`.

## Сбор и подготовка данных

Сборщик принимает диапазон идентификаторов отзывов. Начинайте с небольшого
диапазона, соблюдайте правила сайта-источника и не запускайте несколько
сборщиков одновременно.

```bash
python parser/main.py --start 12623892 --end 12623902 --write-header
```

Результат добавляется в `parser/20_02parseres.csv`. Дальнейшая очистка описана
в `parser/preprocessor.py`; для обучения и инференса используются
`parser/finetune.py` и `parser/usemodel.py` соответственно. Эти ML-скрипты
загружают модели из Hugging Face при первом запуске.

## Воспроизводимость и ограничения

- CSV-файлы в репозитории — снимок данных на момент сбора, а вёрстка сайта
  источника может меняться и потребовать обновления CSS-селекторов сборщика.
- Тональность определяется моделью и её вероятностями; это не ручная
  разметка, поэтому результаты следует интерпретировать как модельную оценку.
- Обученная локальная модель и временные артефакты не попадают в Git — они
  перечислены в `.gitignore`.
